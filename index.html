Rotating Flower Animation

An interactive p5.js project

About the Project

This project is a rotating flower animation created using p5.js. The flower spins around the center of the canvas, with its petals moving smoothly as it turns.

It also includes interactive controls that allow users to change the rotation speed and pause or resume the animation.

How to Use

  • Long Press Gradually increases the flower's rotation speed.
  • Short Tap Pauses or resumes the animation.
